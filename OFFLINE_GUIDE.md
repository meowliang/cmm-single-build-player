# CMM Player - Offline Usage Guide

## Overview

The CMM Player is now a Progressive Web App (PWA) that can work offline! This means you can download all the audio, video, and image content ahead of time and use the app without an internet connection.

## Features

### 🚀 **Offline Capabilities**
- **Download & Cache**: Preload all content for offline use
- **Install as App**: Add to home screen on mobile devices
- **Automatic Caching**: Media files are cached as you use them
- **Offline Detection**: App shows when you're offline and uses cached content

### 📱 **Install as App**
- **Mobile**: Tap "Install" when prompted or use browser menu
- **Desktop**: Click the install button in the address bar
- **Benefits**: App-like experience, works offline, faster loading

## How to Use Offline Mode

### 1. **First Time Setup (Online Required)**
1. Open the CMM Player in your browser
2. Look for the download icon (📥) in the player controls
3. Tap the download icon to open the offline menu
4. Select "Preload All Content"
5. Wait for all files to download (you'll see progress updates)
6. Once complete, you'll see "Preload complete!" message

### 2. **Using the App Offline**
- **After preloading**: Turn off WiFi/mobile data
- **Open the app**: It will work normally using cached content
- **Status indicator**: Look for the offline indicator in the top-left corner
- **All features work**: Audio, XR videos, artwork, and navigation

### 3. **Offline Menu Options**
Tap the download icon (📥) to access:
- **Preload All Content**: Download everything for offline use
- **Cache Status**: See how many files are cached
- **Clear Cache**: Remove all cached files (frees up storage)

## Installation Instructions

### **Mobile Devices (iOS/Android)**

#### **Safari (iOS)**
1. Open the CMM Player in Safari
2. Tap the Share button (📤)
3. Scroll down and tap "Add to Home Screen"
4. Tap "Add" to confirm
5. The app will appear on your home screen

#### **Chrome (Android)**
1. Open the CMM Player in Chrome
2. Tap the menu (⋮) in the top-right
3. Tap "Add to Home screen"
4. Tap "Add" to confirm
5. The app will appear on your home screen

#### **Other Browsers**
- **Firefox**: Menu → "Add to Home Screen"
- **Edge**: Menu → "Add to Home Screen"

### **Desktop (Chrome/Edge/Firefox)**
1. Open the CMM Player in your browser
2. Look for the install button in the address bar (📱 icon)
3. Click "Install" to add to your desktop
4. The app will open in its own window

## Storage Requirements

### **Estimated Storage Needed**
- **Audio files**: ~50-100MB per tour
- **XR videos**: ~200-500MB per tour (depending on quality)
- **Artwork**: ~10-20MB per tour
- **Total per tour**: ~300-700MB

### **Managing Storage**
- Use "Cache Status" to see current storage usage
- Use "Clear Cache" to free up space
- Re-download content when needed

## Troubleshooting

### **App Won't Install**
- **iOS**: Make sure you're using Safari
- **Android**: Make sure you're using Chrome or a supported browser
- **Desktop**: Make sure you're using a modern browser (Chrome, Edge, Firefox)

### **Content Won't Load Offline**
- **Check preload**: Make sure you completed the preload process
- **Check storage**: Ensure you have enough device storage
- **Re-download**: Try clearing cache and preloading again

### **App Shows "Offline" but Content Works**
- This is normal! The app is using cached content
- The offline indicator just shows your connection status

### **Slow Loading**
- **First time**: Content needs to download (normal)
- **Subsequent visits**: Should be much faster with cached content
- **Large files**: XR videos may take time to load initially

## Tips for Best Experience

### **Before Going Offline**
1. **Preload content** when you have good WiFi
2. **Test offline mode** before your trip
3. **Check storage** to ensure you have enough space
4. **Install the app** for better performance

### **During Offline Use**
1. **Keep the app open** to avoid reloading
2. **Use airplane mode** to test offline functionality
3. **Don't clear browser data** (it removes cached content)

### **Managing Multiple Tours**
- **Preload one tour at a time** to manage storage
- **Clear old tours** when you're done with them
- **Re-download** when you want to revisit a tour

## Technical Details

### **What Gets Cached**
- Audio files (.mp3)
- XR video files (.mp4)
- Artwork images (.jpg, .png)
- App files (HTML, CSS, JavaScript)
- Playlist data

### **Cache Strategy**
- **Static files**: Cached immediately on first visit
- **Media files**: Cached as you use them
- **Preload**: Downloads all content at once
- **Updates**: Automatically downloads new versions when online

### **Storage Limits**
- **Mobile**: Limited by device storage
- **Desktop**: Limited by browser storage (usually 50MB-1GB)
- **Progressive**: Older content may be removed if storage is full
